# MERN User Management System - Backend

## 📌 Features
- REST APIs for user management (CRUD operations)  
- User authentication using JWT  
- Password hashing using bcrypt  
- Image upload using multer  
- Secure session handling using passport and cookie-session  
- Rate limiting using express-rate-limit  
- Cross-origin requests handled using CORS  

## 🛠️ Tech Stack
- Node.js  
- Express.js  
- MongoDB  
- JWT Authentication  
- bcrypt  
- multer  
- passport  
- cookie-session  
- express-rate-limit  
- CORS
